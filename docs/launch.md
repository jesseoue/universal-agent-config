# Launch plan

## Positioning

For developers using multiple coding agents, Universal Agent Config is the open-source routing brain that turns one canonical config into native OpenCode, omp, Claude Code, Codex, Cursor, Aider, and Goose settings.

## One-sentence pitch

Stop maintaining seven copies of your AI coding agent config.

## Launch sequence

1. Publish the repository with a clean README and compatibility matrix.
2. Share the comparison table in AI/dev communities.
3. Post the routing-technology decision matrix separately.
4. Publish a walkthrough: one model change updating all seven agents.
5. Add a demo GIF showing install and model drift refresh.
6. Reach out to agent maintainers for adapter feedback.
7. Create issues for runtime smoke tests against each agent CLI.
